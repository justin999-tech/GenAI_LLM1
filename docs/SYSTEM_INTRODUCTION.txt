Author: Justin     Course: GenAI Lab 2
GitHub: https://github.com/justin999-tech/GenAI_LLM1


OVERVIEW

An agentic web chatbot extending HW01 with the five v2 features. Python Flask backend, vanilla-JS glassmorphism frontend, plus an isolated MCP (Model Context Protocol) server subprocess that exposes 23 real tools to the model.


HW02 REQUIRED FEATURES

1. Auto Routing — router.py picks one of 5 Groq models per request (vision / fast / long-context / default) based on payload signals.

2. Multimodal — Drag-drop image upload, base64-encoded into an OpenAI-format image_url array, auto-routed to Llama 4 Scout vision model.

3. Long-term Memory — memory.py backs an SQLite store. A background 8B thread extracts facts from USER turns only; before each turn, top-5 relevant memories are injected into the system prompt via hybrid CJK-bigram + ASCII tokenization.

4. Tool Use + MCP — mcp_server.py subprocess speaks JSON-RPC over stdio using the official mcp SDK and exposes 23 tools. tools.agentic_stream() runs a multi-round function-calling loop with local fallback if MCP is offline.

5. Other Features — Multi-provider (OpenAI / Claude / OpenRouter / etc.), sandboxed Python interpreter with matplotlib capture, free image generation (Pollinations.ai), Notion API integration, inline HTML/SVG/Mermaid artifact preview, and a 9-chart analytics dashboard.


23 MCP TOOLS (8 MODULES)

   Basic        calculator, get_datetime, web_search, get_weather
   Generation   generate_image (8 styles)
   Filesystem   read_file, write_file, list_directory, search_files
   Web          fetch_url, github_search_repos, github_read_file, youtube_transcript
   Academic     arxiv_search, wikipedia_search
   Finance      stock_price, crypto_price
   Code         execute_python (sandboxed, captures matplotlib)
   Notion       search, list_pages, create_page, append_to_page, query_database


TECH STACK

Python 3.10, Flask, SQLite, official mcp SDK, Groq API, Chart.js, marked.js, highlight.js, KaTeX, Mermaid.js, Pollinations.ai
